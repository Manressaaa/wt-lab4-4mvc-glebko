# WT-4 ASP.NET Core MVC

Лабораторная работа WT-4: разработка веб-приложения на ASP.NET Core MVC.

Предметная область: **Авиакомпания** (сущность `Flight`).

## Функциональность

- Список рейсов
- Подробная информация о рейсе
- Добавление нового рейса
- Редактирование рейса
- Валидация форм

## Технологии

- ASP.NET Core MVC (.NET 8)
- Razor Views
- Bootstrap 5
- Docker
- Render
